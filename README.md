# Capacita a tus empleados con Microsoft 365 Copilot: Casos de uso Operaciones y Servicio

Este curso proporciona a profesionales de Operaciones y Servicio una experiencia práctica para utilizar Microsoft 365 Copilot como apoyo en análisis de datos operativos, diagnóstico de servicio y creación asistida de artefactos técnicos. El caso transversal parte de un deterioro en un indicador y utiliza un modelo de datos, información operativa y requisitos de privacidad para convertir preguntas de negocio en análisis y acciones verificables. La sesión integra Copilot Chat, Copilot Notebooks, Analista y las aplicaciones Excel, Word, PowerPoint y Outlook. Los participantes interpretarán diagramas de modelos de datos, solicitarán consultas SQL, mejorarán o generarán fórmulas M/DAX para Power BI y crearán scripts de Python para anonimización, aplicando criterios de revisión antes de utilizar los resultados.
